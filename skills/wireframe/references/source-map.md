## How to use this map

- **Making a claim the book makes?** Name the origin from the table above.
- **Making a claim the book doesn't make?** Say so — the skills are explicitly
  "extended with production practice," and that extension must stay visible.
- **A "—" above is not a defect.** It means the skill teaches the chapter's idea
  without leaning on that particular source. Only add an attribution when the skill
  is actually using that source's specific contribution.

## Where the skills deliberately diverge from the book

| Book | These skills | Why |
|---|---|---|
| "Early-phase / middle-phase" wireframes; "a single color"; "a limited color palette" | A five-rung ladder (no-fi / low-fi / mid-fi / late-phase / hi-fi) and "grayscale" | Shorthand that maps to agent-legible fidelity decisions. The book's phase vocabulary is the authority; this is a naming convenience. |
| "Placeholders for the content" | Explicit lorem rules (real labels, buttons, nav, headings; lorem only for body) | The book states the principle; the skills specify where it binds. |
| No dispatcher | `wireframe` router | Packaging for agents, not a book concept. |
